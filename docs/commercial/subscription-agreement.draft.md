## B. 과금 모델 옵션 (택1, 사업 결정) 【사업결정】

1. **제품 라인당(Per-Product)** — 소프트웨어를 포함하는 라이선시 제품 라인 수 기준.
   임베디드/디바이스 제조사에 단순.
2. **디바이스 수량 티어(Per-Device tier)** — 출하 디바이스 수 구간별 요금. 대량 출하에
   비례 과금.
3. **사이트/조직(Site/Org-wide)** — 조직 단위 정액. 사용량 추적 부담이 큰 경우.
4. **좌석(Per-Seat)** — 개발자 수 기준. 라이브러리 임베딩 모델엔 덜 적합(주로 도구형).

> 권고 출발점: **제품 라인당 + 디바이스 티어 혼합** (기본 라인 요금 + 대량 출하 시 티어
> 상향). B2B 임베디드 코덱에 흔한 구조. 최종 결정·금액은 사업 측.

## C. 마스터 조건 요지 (Master Terms — EULA 와 정합)

- **편입.** 본 구독 계약은 EULA(사용 허락·제한·IP·보증·**책임 한도**)를 편입한다. 상충
  시 우선순위: 주문서 > 마스터 조건 > EULA. 【법률검토】
- **갱신/해지.** §6 EULA 및 주문서 자동 갱신·통지 기간에 따른다. 중대 위반 시정 불이행
  시 해지(§8 EULA).
- **요금/세금.** 연간 선청구 원칙(택), 세금 별도, 환불 불가(보증 구제 §9 EULA 제외).
  연체 시 정지/해지 + 적법 한도 연체이자. 【사업결정】
- **승인 범위 초과.** 초과 사용 적발 시 소급 정산 + 추가 요금. 감사권(§12 EULA).
- **책임 한도(필수).** EULA §10 을 그대로 적용 — 간접손해 배제 + 총액 한도(직전 12개월
  지급 구독 요금). 본 골자에서 별도 상향하지 않는다. 【법률검토】
- **데이터.** 라이선서는 라이선시 데이터를 처리하지 않는다(온프레미스 라이브러리). 지원
  과정의 진단 데이터 취급은 별도 명시. 【법률검토】

## D. 지원 등급(SLA) 골자 — 구독 포함 【사업결정 / 법률검토 수치】

| 항목 | Standard | Premium |
|---|---|---|
| 채널 | 이메일/이슈 | 이메일 + 우선 큐 |
| 업데이트 | 구독 기간 중 전 버전 | 동일 + 사전(early) 빌드 |
| 심각도 1(프로덕션 중단) 초기 응답 | 〔2 영업일〕 | 〔4 시간〕 |
| 심각도 2(주요 기능 저하) | 〔3 영업일〕 | 〔1 영업일〕 |
| 심각도 3(질의/경미) | 〔5 영업일〕 | 〔2 영업일〕 |
| 보안 패치 | 제공 | 우선 제공 + 사전 통지 |
| 운영 시간 | 영업일/업무시간 | 확장 |

> 위 수치는 **예시 플레이스홀더**다. "응답(response)"은 해결(resolution) 보증이 아니며,
> SLA 미달 시 구제(크레딧 등) 여부·범위는 사업/법률 결정. 【법률검토】
